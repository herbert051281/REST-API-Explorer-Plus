Installation Guide

ServiceNow API Explorer Plus lets you browse ServiceNow tables and fields, then instantly generate Power BI–ready REST API URLs and Power Query M code — right from your browser. Follow the steps below to install it in Microsoft Edge or Google Chrome.

Microsoft Edge Google Chrome ~2 minutes to install
Step 1
Open the SharePoint library
Open the SharePoint site link shared with you. You'll land on the Project & Document Templates and Wiki library. Click the REST API Explorer Plus Extension folder to open it.
Step 2
Sync via the Library ribbon
Click the Library tab at the top of the page to open the ribbon, then click Sync. Follow the OneDrive prompts to complete the sync. Only needed once — OneDrive keeps the folder current automatically after this.
Step 3
Find the synced folder
After syncing, open File Explorer. The folder will be at:

C:\Users\YourUsername\RSM\Customer Success - Project & Document Templates and Wiki\REST API Explorer Plus Extension This is the folder you'll point your browser at — never move or rename it.
Step 4
Open the Extensions page
Edge: type edge://extensions in the address bar and press Enter.

Chrome: type chrome://extensions instead.
Step 5
Enable Developer Mode
In the top-right corner of the Extensions page, toggle Developer mode on.
Step 6
Load the extension
Click Load unpacked, then select the synced folder from Step 2. The extension appears as ServiceNow API Explorer Plus.
Step 7
Pin to your toolbar
Click the puzzle-piece 🧩 icon in your toolbar, find API Explorer Plus, and click the pin so it stays visible.
↺

Getting updates — no download needed

When a new version is released, OneDrive syncs the updated files to your computer automatically. Just go to edge://extensions (or chrome://extensions), find ServiceNow API Explorer Plus, and click the reload ↺ icon. That's it — no unzipping, no re-installing.

How to use

Navigate to any ServiceNow list, form, or report page, then click the API Explorer Plus icon in your browser toolbar. The panel auto-detects the current table and fields.

Output options

Use the REST API URL tab to copy the endpoint for direct use, or the Power Query M tab to copy syntax-highlighted M code ready to paste into Power BI's Advanced Editor.
