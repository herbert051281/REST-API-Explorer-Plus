Privacy Policy — REST API Explorer Plus

Last updated: June 2026

What this extension does

REST API Explorer Plus is a browser extension that reads data from the ServiceNow tab you are currently viewing and generates Power BI-ready REST API URLs and Power Query M code for your own use.

Data collection

  • The extension does not collect, transmit, or store any personal data.
  • All API calls are made directly from your browser to the ServiceNow instance you are already logged into — no data passes through any third-party server.
  • No analytics, telemetry, or tracking of any kind is included.

Permissions

The extension requests activeTab and scripting permissions solely to inject the tool panel into the active ServiceNow tab when you click the toolbar icon. It has no standing access to any tab or browsing activity.
